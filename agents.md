## Important

### Naming

Always use PascalCase for classes, snake_case for variables and constants, and kebab-case for files. Always use English for names, comments and code. No emojis anywhere.

### Folder Structure

Respect current folder structure. Only add new files if strictly necessary and always in the most logical folder. If a folder is missing, ask first before creating it, even if you are sure where it should be.

### Documentation

Always keep documentation updated. Docs in /docs folder, comments in code, inline where appropriate.

### Commits

Always create atomic commits following the conventional commits specification. Always add a short description and a detailed explanation of the changes made. Use English for commit messages.
